# ESP8266 Traffic Light System 🚦
#video on project https://youtu.be/309O3pOn1Xg

This project demonstrates a simple traffic light system using a NodeMCU (ESP8266) and LEDs.

## 🔧 Components Used
- NodeMCU ESP8266
- Red LED
- Yellow LED
- Blue / Green LED
- 220Ω Resistors (3)
- Breadboard
- Jumper Wires
- USB Cable

## 🔌 Connections
| LED Color | NodeMCU Pin |
|---------|------------|
| Red     | D1         |
| Yellow  | D2         |
| Blue    | D5         |

All LED negative terminals are connected to GND.

## ⚙️ Working
- Red LED ON for 5 seconds
- Yellow LED ON for 2 seconds
- Blue/Green LED ON for 5 seconds
- Cycle repeats continuously

## 🧪 Board Test
The built-in LED blink test was used to confirm board functionality before connecting external LEDs.
